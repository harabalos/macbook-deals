## Κλειδιά και κωδικοί
Το repo είναι public. **Κανένα token ή κωδικός δεν μπαίνει σε αρχείο.** Όλα μπαίνουν μόνο στα GitHub Secrets (βήμα 3), και το GitHub τα κρύβει με `***` και στα logs. Επιπλέον:
- τα μηνύματα σφάλματος που γράφονται στο δημόσιο `state.json` περνάνε από φίλτρο που σβήνει όποιο secret εμφανιστεί
- αρχεία `.env` δεν μπαίνουν ποτέ σε commit (`.gitignore`)
- χωρίς Telegram secrets το workflow δεν κάνει τίποτα

## Στήσιμο (μία φορά)

### 1. Telegram bot
1. Στο Telegram άνοιξε τον **@BotFather** → `/newbot` → δώσε όνομα. Σου δίνει ένα **token**.
2. Άνοιξε το bot σου, πάτα **Start** και στείλε του ένα οποιοδήποτε μήνυμα.
3. Άνοιξε στον browser το `https://api.telegram.org/bot<TOKEN>/getUpdates` και βρες το `"chat":{"id":123456789` → αυτό είναι το **chat id**.

### 2. Gmail για τα newsletters
1. Φτιάξε **καινούριο Gmail μόνο γι' αυτό**, για να μην έχει το bot πρόσβαση στο κανονικό σου mail.
2. Ενεργοποίησε το 2-Step Verification και μετά φτιάξε **App password** στο https://myaccount.google.com/apppasswords.
3. Γράψε αυτό το email στα newsletters των Κωτσόβολος, Πλαίσιο, Public, iStorm, You, BestPrice και Skroutz (συνήθως η φόρμα είναι στο footer).
4. Τις πρώτες μέρες κοίτα τα Ανεπιθύμητα και κάνε «Δεν είναι ανεπιθύμητο». Το bot διαβάζει μόνο τα Εισερχόμενα (και τα Promotions μετράνε).

### 3. GitHub secrets
Κάθε εντολή ζητάει την τιμή και την κρατάει κρυφή:
```bash
gh secret set TELEGRAM_BOT_TOKEN
gh secret set TELEGRAM_CHAT_ID
gh secret set IMAP_USER        # το νέο gmail
gh secret set IMAP_PASSWORD    # το app password (16 γράμματα)
```

### 4. Πρώτη εκτέλεση
Δοκιμή χωρίς Telegram: δείχνει στο log τι θα έστελνε, χωρίς να στείλει ή να αποθηκεύσει τίποτα.
```bash
gh workflow run watch -f dry_run=true
```
Η κανονική πρώτη εκτέλεση, αφού μπουν τα secrets:
```bash
gh workflow run watch
```
Σε 2-3 λεπτά πρέπει να έρθει στο Telegram το «🚀 Ξεκίνησα!». Μαζί έρχονται όσες μεγάλες εκπτώσεις τρέχουν ήδη.

## Ρυθμίσεις
Στην αρχή του `watcher.py`: όρια ειδοποίησης (`LOUD_DROP_EUR`, `LOUD_DROP_PCT`, …), ώρα πρωινής αναφοράς, λέξεις για τα newsletters.

## Τοπικά, για πιο γρήγορο έλεγχο (π.χ. Black Friday)
Το GitHub τρέχει το πολύ κάθε 5 λεπτά, και τις ώρες αιχμής μπορεί να καθυστερήσει. Τις μέρες που μετράει κάθε λεπτό, άφησε να τρέχει και στο Mac:
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
.venv/bin/python watcher.py --loop 90
```
Το Mac κρατάει δικό του `state.json`, οπότε μπορεί κάποια ειδοποίηση να έρθει δύο φορές. Αυτό είναι καλύτερο από το να χαθεί.

## Όρια
- **Το Πλαίσιο μπλοκάρει τους servers του GitHub (403)**, οπότε εκεί παραλείπεται (`SKIP_SOURCES` στο workflow). Οι τιμές του φαίνονται μέσα από το BestPrice όταν είναι το φθηνότερο κατάστημα. Για πλήρη κάλυψη του Πλαισίου τρέξε το στο Mac: `.venv/bin/python watcher.py --only plaisio --loop 120`
- Το GitHub Actions δεν εγγυάται ακριβώς 5 λεπτά: τις ώρες αιχμής ένας έλεγχος μπορεί να αργήσει 10-20 λεπτά.
- Η Public δεν δείχνει απόθεμα στη λίστα της, οπότε εκεί βλέπουμε μόνο τιμή.
- Αν ένα κατάστημα αλλάξει τη σελίδα του, θα έρθει ⚠️ και αυτό το κομμάτι του κώδικα θα θέλει διόρθωση.
- Το bot **δεν αγοράζει**. Για να προλαβαίνεις, κράτα το κινητό συνδεδεμένο σε Κωτσόβολο, Πλαίσιο και Public, με αποθηκευμένη διεύθυνση και κάρτα.
